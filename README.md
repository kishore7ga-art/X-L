# XITE Institutional Platform — Complete 13-Section Master Build

A production-ready Next.js 16 + React 19 + TypeScript project containing **all 13 Cinematic Sections** of the XITE website built with Tailwind CSS v4, GSAP ScrollTrigger, Lenis Smooth Scroll, and 3900 total image sequence frames (`public/section1/` through `public/section13/`).

---

## 🚀 Quick Start

### Installation

```bash
npm install
```

### Local Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
```
